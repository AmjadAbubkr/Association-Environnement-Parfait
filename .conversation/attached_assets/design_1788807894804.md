# Verdant — Website Design Specification

## 1. Design Direction

**Design concept:** Sustainable, modern, editorial eco-brand.

The website should communicate environmental responsibility through:
- Large, high-quality nature photography
- Clean white space
- Strong black typography
- Natural green accents
- Editorial-style layouts
- Minimal borders and restrained UI
- Large photographic sections balanced with compact information cards

The overall feeling should be **premium, calm, natural, trustworthy, and contemporary** rather than overly decorative or stereotypically "green."

---

## 2. Visual Identity

### Brand

**Name:** Verdant

**Brand positioning:** A modern environmental/lifestyle organization focused on sustainable living, conservation, community action, and eco-friendly initiatives.

### Logo

Use a simple leaf-based icon followed by the wordmark:

`[leaf icon] verdant`

- Wordmark: lowercase
- Heavy/semibold sans-serif
- Black or very dark charcoal
- Leaf icon uses natural green tones
- Keep the logo compact and horizontally aligned

---

## 3. Color System

Use a restrained palette.

| Token | Suggested Color | Usage |
|---|---|---|
| `--color-background` | `#FFFFFF` | Main page background |
| `--color-text` | `#111111` | Headings and primary text |
| `--color-muted` | `#6F6F6F` | Supporting text |
| `--color-green` | `#5FAF45` | Brand/accent color |
| `--color-green-dark` | `#397A32` | Hover states / emphasis |
| `--color-green-light` | `#EAF4E7` | Soft backgrounds |
| `--color-border` | `#D9D9D9` | Cards and dividers |
| `--color-page-tint` | `#F3F6F3` | Optional subtle section background |

Do not make the entire website green. Green should be an accent while **white, black, and photography dominate the visual system**.

---

## 4. Typography

Use a modern geometric or contemporary sans-serif.

Recommended:
- **Primary:** Inter
- Alternatives: Manrope, DM Sans, Helvetica Neue, Arial

### Typography hierarchy

#### Hero heading
- Large
- Weight: 500–600
- White over photography
- Desktop: approximately `48–64px`
- Mobile: approximately `32–40px`

#### Section heading
- Weight: 600–700
- Desktop: `42–52px`
- Mobile: `32–38px`

#### Large promotional heading
- Weight: 700
- Uppercase where appropriate
- Desktop: `42–56px`
- Tight line height: around `0.95–1.05`

#### Body
- `15–18px`
- Line height: `1.5–1.7`
- Maximum text width: approximately `600–700px`

#### Navigation
- `12–14px`
- Medium weight
- Clean and understated

---

# 5. Global Layout

The design uses a centered content container.

### Desktop

- Maximum content width: `1200–1280px`
- Horizontal page padding: `32–48px`
- Section spacing: `96–140px`
- Card gaps: `16–32px`

### Mobile

- Horizontal padding: `20px`
- Section spacing: `64–88px`
- Cards stack vertically
- Navigation collapses into a mobile menu

The page should have generous white space. Avoid filling every area with content.

---

# 6. Header / Navigation

The header is white and minimal.

### Structure

```text
Home    About Us    Initiatives       [leaf] verdant       Blog   Resources   Get Involved
```

### Desktop behavior

- Full-width white header
- Centered max-width container
- Logo visually centered
- Navigation groups placed around the logo
- Small typography
- No heavy navigation borders
- Header height around `70–90px`

### Mobile behavior

- Logo aligned left or centered
- Hamburger button on the opposite side
- Hide desktop navigation links
- Full-screen or dropdown navigation menu

### Navigation links

- Home
- About Us
- Initiatives
- Blog
- Resources
- Get Involved

# 7. Hero Section

The hero is the strongest visual element.

Use a large rectangular photograph of fresh green leaves covered in water droplets.

### Layout

```text
┌──────────────────────────────────────────┐
│                                          │
│          Sustainable Green Living        │
│     Plants, Tips, and Inspiration...     │
│                                          │
│              [Nature Image]              │
│                                          │
└──────────────────────────────────────────┘
```

### Image

- Full-width within the content container
- Approximately `16:6` or `16:7`
- High-resolution nature photography
- Green foliage
- Water/dew droplets
- No artificial-looking illustrations

### Overlay

Use a subtle dark/transparent overlay only if required for text readability.

### Hero text

**Heading:**

> Sustainable Green Living

**Supporting text:**

> Plants, Tips, and Inspiration for Eco Warriors — A Greener Future Starts Here.

Text should be centered vertically and horizontally.

# 14. Photography Direction

Photography is a major part of the design.

### Preferred imagery

- Fresh green leaves
- Forest canopies
- Tree planting
- Hands interacting with soil/plants
- Sustainable products
- Recycling
- Outdoor environmental activities
- Natural textures
- Water droplets on leaves

### Image treatment

Images should look:
- Natural
- Bright
- High resolution
- Editorial
- Authentic

Avoid:
- Generic corporate stock photography
- Excessive filters
- Oversaturated neon green
- Cartoon environmental illustrations
- Images with large amounts of embedded text

---

# 15. Image Aspect Ratios

Recommended image ratios:

| Component | Ratio |
|---|---|
| Hero | `16:6` / `16:7` |
| Initiative card | `4:5` |
| Commitment image | `4:5` |
| Forest CTA | `16:6` |
| Small category images | `1:1` or `4:3` |

Use `object-fit: cover` consistently.

# 17. Buttons

Buttons should be simple and rectangular.

### Primary

- Black background
- White text
- Small/medium size
- Minimal radius: `0–4px`
- Medium font weight

Example:

`GET IN TOUCH`

### Secondary

- Transparent
- Black border
- Black text

### Hover

- Slight background transition
- No exaggerated animation

---

# 18. Icons

Use simple line icons.

Recommended icon style:
- Thin/medium stroke
- Green
- Minimal detail
- Consistent stroke width

Possible icon sources:
- Lucide
- Phosphor
- Custom SVG icons

Do not mix multiple icon styles.

---

# 19. Borders and Shadows

The design is mostly flat.

### Borders

Use:

```css
border: 1px solid #D9D9D9;
```

### Shadows

Use only subtle shadows for floating cards:

```css
box-shadow: 0 12px 40px rgba(0, 0, 0, 0.06);
```

Avoid:
- Heavy drop shadows
- Glows
- Glassmorphism
- Excessive rounded cards

---

# 20. Responsive Design

### Desktop: ≥ 1024px

- Full navigation
- Large hero
- Multi-column initiative cards
- Overlapping commitment layout
- Horizontal category navigation

### Tablet: 768–1023px

- Reduced typography
- Smaller content gaps
- Keep multi-column layouts where practical
- Navigation may simplify

### Mobile: < 768px

- Hamburger navigation
- Hero becomes approximately `4:3` or `16:9`
- Initiative cards stack
- Commitment image and card stack instead of overlapping
- CTA card becomes a normal block
- Category strip becomes horizontally scrollable or a grid
- Footer columns stack
- Reduce large headings while preserving strong hierarchy

---

# 21. Motion

Animation should be subtle.

Recommended:
- Image hover zoom: `transform: scale(1.03)`
- Button transitions: `150–250ms`
- Fade/slide reveal on scroll
- Navigation transitions
- Card hover elevation

Avoid:
- Excessive parallax
- Large bouncing animations
- Constant motion
- Slow page transitions

The site should feel calm and natural.

---

# 22. Accessibility

Requirements:

- WCAG-conscious color contrast
- All images require meaningful `alt` text
- Decorative images use empty alt attributes
- Buttons must have clear labels
- Keyboard navigation must work
- Visible focus states
- Do not rely on color alone to communicate state
- Respect `prefers-reduced-motion`

---

# 25. Design Rules

### Do

- Prioritize photography
- Use generous white space
- Keep typography bold and clean
- Use green as an accent
- Maintain strong visual hierarchy
- Use asymmetric/editorial compositions
- Keep cards simple
- Make the site feel premium and trustworthy

### Do not

- Make every element green
- Use excessive rounded corners
- Use heavy gradients
- Use excessive shadows
- Overload sections with text
- Use generic environmental clipart
- Use overly playful animations
- Turn the website into a typical corporate dashboard

---

# 26. Overall Page Flow

The final page should visually follow this rhythm:

```text
HEADER
   ↓
LARGE NATURE HERO
   ↓
3 INITIATIVE IMAGE CARDS
   ↓
OUR COMMITMENT
   ↓
IMAGE + OVERLAPPING ABOUT CARD
   ↓
FOREST CTA
   ↓
INITIATIVE CATEGORY STRIP
   ↓
EMPOWERING ECO WARRIORS
   ↓
NEWSLETTER + BRAND + GET IN TOUCH
```

The key design principle is **photography + typography + whitespace**.

The reference design should be treated as the visual direction: clean editorial environmental branding with strong nature imagery, bold typography, minimal UI, and structured asymmetrical layouts.
